Theme & Orientation

The NAVER Maps app propagates its current color scheme (light / dark) and device orientation (portrait / landscape) to your webview. You can consume these values via CSS media queries, JavaScript event listeners, or — for SSR use cases — by parsing the User-Agent string.

CSS (Recommended)​

The simplest and most reliable approach is to use standard CSS media queries. The app synchronizes prefers-color-scheme and orientation with the native state, so these queries respond to real-time changes automatically.

Theme​

/* Light mode — applied by default */
body {
  background-color: #ffffff;
  color: #000000;
}

@media (prefers-color-scheme: dark) {
  body {
    background-color: #121212;
    color: #ffffff;
  }
}

Orientation​

@media (orientation: portrait) {
  .layout {
    flex-direction: column;
  }
}

@media (orientation: landscape) {
  .layout {
    flex-direction: row;
  }
}

JavaScript​

Use window.matchMedia to read the current state or subscribe to changes:

// Read current values
const isDark = window.matchMedia('(prefers-color-scheme: dark)').matches
const isPortrait = window.matchMedia('(orientation: portrait)').matches

// Subscribe to changes
window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', (e) => {
  console.log('Dark mode:', e.matches)
})

window.matchMedia('(orientation: portrait)').addEventListener('change', (e) => {
  console.log('Portrait:', e.matches)
})

Server-Side Rendering (SSR)​

When rendering on the server, media queries are not available. Instead, parse the User-Agent request header using the getWebviewContext() utility.

User-Agent Format​

When the NAVER Maps app opens a webview, it appends the following token:

WebViewSDK(map; {theme}; {orientation})

Values:

  • theme: light | dark
  • orientation: portrait | landscape

Usage​

import { getWebviewContext } from '@maps-service/maps-bridge'

// Server-side (e.g. in a Next.js getServerSideProps)
const { theme, orientation } = getWebviewContext({
  userAgentHeader: request.headers['user-agent'] ?? '',
})

// theme → 'light' | 'dark' | undefined
// orientation → 'portrait' | 'landscape' | undefined

See getWebviewContext() for the full API reference.

tip

Use the UA approach only for SSR or server-side analytics. For all client-side styling and interaction, prefer CSS media queries — they respond to changes automatically without additional JavaScript.
