Safe Area

Modern mobile devices have hardware features — notches, camera cut-outs, rounded corners, and home indicators — that encroach on the usable screen area. The NAVER Maps app injects safe area inset values as CSS custom properties into your webview so you can offset your layout accordingly.

Setup​

Add viewport-fit=cover to your viewport meta tag. This instructs the browser to extend your page's rendering surface to fill the entire screen (including areas behind hardware cut-outs), giving you precise control over insets via CSS.

<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover" />

Without this attribute, the browser applies default insets and the CSS variables below will have no visible effect.

CSS Custom Properties​

The app sets the following custom properties on the document root:

PropertyDescription
--safe-area-inset-topHeight of the top inset (e.g. status bar, notch)
--safe-area-inset-rightWidth of the right inset
--safe-area-inset-bottomHeight of the bottom inset (e.g. home indicator)
--safe-area-inset-leftWidth of the left inset

Applying Safe Area Insets​

CSS (Recommended)​

Apply padding to your root element using the CSS custom properties:

body {
  padding-top: var(--safe-area-inset-top);
  padding-right: var(--safe-area-inset-right);
  padding-bottom: var(--safe-area-inset-bottom);
  padding-left: var(--safe-area-inset-left);
}

If only certain edges need protection (e.g. a fixed bottom bar), apply selectively:

.bottom-bar {
  padding-bottom: var(--safe-area-inset-bottom);
}

JavaScript​

If you need the inset values in JavaScript (e.g. for canvas rendering or programmatic layout), read them from getComputedStyle:

const style = getComputedStyle(document.documentElement)
const insetTop = parseFloat(style.getPropertyValue('--safe-area-inset-top')) || 0
const insetBottom = parseFloat(style.getPropertyValue('--safe-area-inset-bottom')) || 0

For React applications, a reusable hook:

import { useEffect, useState } from 'react'

export function useSafeAreaInsets() {
  const [insets, setInsets] = useState({ top: 0, right: 0, bottom: 0, left: 0 })

  useEffect(() => {
    const style = getComputedStyle(document.documentElement)
    const parseInset = (v: string | null) => (v ? parseFloat(v.replace('px', '')) : 0)

    const update = () => {
      setInsets({
        top:    parseInset(style.getPropertyValue('--safe-area-inset-top')),
        right:  parseInset(style.getPropertyValue('--safe-area-inset-right')),
        bottom: parseInset(style.getPropertyValue('--safe-area-inset-bottom')),
        left:   parseInset(style.getPropertyValue('--safe-area-inset-left')),
      })
    }

    update()
    window.addEventListener('resize', update)
    return () => window.removeEventListener('resize', update)
  }, [])

  return insets
}
