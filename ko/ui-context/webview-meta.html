WebView Meta

WebView Meta는 페이지 로드 시 상태바 색상 등의 네이티브 UI 설정을 사전에 선언할 수 있는 설정 객체입니다. SDK 초기화 중에 읽혀 자동으로 네이티브 앱에 전달됩니다.

설정 스키마​

interface WebViewMeta {
  statusBar?: {
    /** 네이티브 상태바의 배경색. 허용 형식: #RRGGBB 또는 #RRGGBBAA. */
    backgroundColor?: string
  }
}

모든 속성은 선택 사항입니다. 생략된 속성은 네이티브 앱의 현재 값을 유지합니다.

적용 방법​

WebView Meta 설정을 적용하는 두 가지 방법이 있습니다.

방법 1 — 선언적 방식 (권장)​

SDK 스크립트 태그 이전에 위치한 <script> 블록에 window.MAPS_WEBVIEW_META를 정의하세요. SDK가 초기화될 때 이 객체를 읽어 setWebViewMeta API를 통해 자동으로 네이티브 앱에 전달합니다.

페이지 로드 중 가장 이른 시점에 처리되므로, 상태바 색상이 잘못된 값으로 잠깐 표시되는 시각적 깜빡임 현상을 방지할 수 있어 이 방식을 권장합니다.

<head>
  <script>
    window.MAPS_WEBVIEW_META = {
      statusBar: {
        backgroundColor: '#ffffff',
      },
    }
  </script>

  <!-- 큐 초기화 스크립트와 SDK 스크립트 태그는 이 뒤에 위치 -->
</head>

방법 2 — 명령적 방식​

SDK 초기화 이후 언제든지 setWebViewMeta()를 호출하여 네이티브 UI 설정을 동적으로 업데이트할 수 있습니다.

MapsJsBridge.setWebViewMeta({
  statusBar: {
    backgroundColor: '#ff3300',
  },
})

런타임 상태에 따라 상태바 색상을 변경해야 할 때(예: 다크/라이트 테마 전환) 유용합니다.

전체 API 레퍼런스는 setWebViewMeta API를 참고하세요.
