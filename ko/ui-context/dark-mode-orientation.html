테마 & 화면 방향

네이버 지도 앱은 현재 색상 테마(라이트/다크)와 기기 방향(세로/가로)을 웹뷰에 전달합니다. CSS 미디어 쿼리, JavaScript 이벤트 리스너, 또는 SSR 환경에서는 User-Agent 문자열 파싱을 통해 이 값들을 활용할 수 있습니다.

CSS (권장)​

가장 간단하고 안정적인 방법은 표준 CSS 미디어 쿼리를 사용하는 것입니다. 앱은 prefers-color-scheme과 orientation을 네이티브 상태와 동기화하므로, 이 쿼리들은 실시간 변경에 자동으로 반응합니다.

테마​

/* 라이트 모드 — 기본값 */
body {
  background-color: #ffffff;
  color: #000000;
}

@media (prefers-color-scheme: dark) {
  body {
    background-color: #121212;
    color: #ffffff;
  }
}

화면 방향​

@media (orientation: portrait) {
  .layout {
    flex-direction: column;
  }
}

@media (orientation: landscape) {
  .layout {
    flex-direction: row;
  }
}

JavaScript​

window.matchMedia를 사용해 현재 상태를 읽거나 변경 이벤트를 구독할 수 있습니다.

// 현재 값 읽기
const isDark = window.matchMedia('(prefers-color-scheme: dark)').matches
const isPortrait = window.matchMedia('(orientation: portrait)').matches

// 변경 이벤트 구독
window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', (e) => {
  console.log('다크 모드:', e.matches)
})

window.matchMedia('(orientation: portrait)').addEventListener('change', (e) => {
  console.log('세로 방향:', e.matches)
})

서버 사이드 렌더링 (SSR)​

서버에서 렌더링할 때는 미디어 쿼리를 사용할 수 없습니다. 대신 getWebviewContext() 유틸리티를 사용하여 User-Agent 요청 헤더를 파싱하세요.

User-Agent 형식​

네이버 지도 앱이 웹뷰를 열 때 다음 토큰을 User-Agent에 추가합니다.

WebViewSDK(map; {theme}; {orientation})

값:

  • theme: light | dark
  • orientation: portrait | landscape

사용 예시​

import { getWebviewContext } from '@maps-service/maps-bridge'

// 서버 사이드 (예: Next.js getServerSideProps)
const { theme, orientation } = getWebviewContext({
  userAgentHeader: request.headers['user-agent'] ?? '',
})

// theme → 'light' | 'dark' | undefined
// orientation → 'portrait' | 'landscape' | undefined

전체 API 레퍼런스는 getWebviewContext()를 참고하세요.

팁

UA 파싱 방식은 SSR이나 서버 사이드 분석에만 사용하세요. 클라이언트 사이드 스타일링과 인터랙션에는 CSS 미디어 쿼리를 사용하는 것이 좋습니다. CSS는 변경 사항에 추가적인 JavaScript 없이 자동으로 반응합니다.
