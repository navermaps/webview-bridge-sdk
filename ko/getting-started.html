시작하기

사전 요구사항​

SDK를 연동하기 전에 아래 요구사항을 충족하는지 확인하세요.

요구사항세부 내용
서비스 IDSDK 초기화에 필요한 고유 식별자입니다. 서비스를 등록하고 serviceId를 발급받으려면 문의하기를 통해 연락해 주세요.
등록된 도메인SDK는 사전 승인된 도메인에서만 초기화됩니다. 서비스 도메인이 serviceId와 함께 등록되어 있어야 합니다.
HTTPS웹뷰 URL은 반드시 https:// 스킴을 사용해야 합니다. HTTP는 지원되지 않습니다.
네이버 지도 앱 버전SDK는 앱 버전 6.0.0 이상이 필요합니다. 일부 API는 더 높은 최소 버전이 필요하며, 개별 API 페이지에서 확인할 수 있습니다.

CDN​

SDK는 CDN을 통해 배포됩니다. 두 가지 버전 관리 전략을 제공합니다.

전략URL동작
메이저 버전https://maps-service.pstatic.net/webview-bridge-sdk/1/external/maps-bridge.js최신 1.x.x 릴리스를 항상 제공합니다. 마이너 및 패치 업데이트가 자동으로 적용됩니다.
고정 버전https://maps-service.pstatic.net/webview-bridge-sdk/1.0.29/external/maps-bridge.js특정 릴리스에 고정됩니다. 업그레이드 시점을 완전히 제어할 수 있습니다.

설정​

페이지의 <head>에 아래 두 블록을 순서대로 추가하세요.

Step 1 — 호출 큐 초기화​

이 인라인 스크립트는 SDK 스크립트가 로드 완료되기 전에 발생하는 MapsJsBridge 호출을 큐에 담아두는 경량 프록시를 생성합니다. SDK <script> 태그보다 앞에 위치해야 합니다.

<script>
  window.MapsJsBridge||(window.MapsJsBridgeApiQueue=[],window.MapsJsBridge=new Proxy({},{get:(e,r)=>(...e)=>{let s,i;const n=new Promise(((e,r)=>{s=e,i=r}));return window.MapsJsBridgeApiQueue.push({method:String(r),args:e,resolve:s,reject:i}),n}}));
</script>

Step 2 — SDK 스크립트 로드​

{version}과 {serviceId}를 실제 값으로 교체하세요.

<script
  type="module"
  src="https://maps-service.pstatic.net/webview-bridge-sdk/{version}/external/maps-bridge.js?serviceId={serviceId}"
></script>

전체 예시​

<html>
<head>
  <!-- 기타 head 요소 -->

  <script>
    window.MapsJsBridge||(window.MapsJsBridgeApiQueue=[],window.MapsJsBridge=new Proxy({},{get:(e,r)=>(...e)=>{let s,i;const n=new Promise(((e,r)=>{s=e,i=r}));return window.MapsJsBridgeApiQueue.push({method:String(r),args:e,resolve:s,reject:i}),n}}));
  </script>
  <script
    type="module"
    src="https://maps-service.pstatic.net/webview-bridge-sdk/1/external/maps-bridge.js?serviceId={serviceId}"
  ></script>
</head>
<body>
  <!-- 페이지 콘텐츠 -->
</body>
</html>

초기화 처리​

SDK가 로드된 후 serviceId와 도메인을 검증하고, 결과를 DOM 이벤트로 알려줍니다.

window.addEventListener('maps-bridge-sdk:init', () => {
  // SDK 준비 완료. MapsJsBridge.isInitialized === true
  console.log('Bridge SDK가 성공적으로 초기화되었습니다.')
})

window.addEventListener('maps-bridge-sdk:error', (event) => {
  // 초기화 실패 — serviceId 및 도메인 등록 상태를 확인하세요.
  console.error('Bridge SDK 초기화 실패:', event.detail.error)
})
팁

maps-bridge-sdk:init 이벤트가 발생하기 전에 호출된 API는 안전합니다. 자동으로 큐에 담겨 SDK가 준비되면 실행됩니다.

주의

maps-bridge-sdk:error가 발생하면 큐에 담긴 모든 API 호출이 실패합니다. 주요 원인:

  • serviceId가 유효하지 않거나 누락된 경우
  • 페이지가 등록되지 않은 도메인에서 제공되는 경우

초기화 이벤트​

이벤트 이름발생 시점
maps-bridge-sdk:initSDK 초기화 성공. MapsJsBridge.isInitialized가 true로 설정됩니다.
maps-bridge-sdk:errorSDK 초기화 실패 (예: 유효하지 않은 서비스 ID, 미등록 도메인).

일관된 구독 해제 처리를 위해 MapsJsBridge.on() / MapsJsBridge.off()를 사용할 수도 있습니다.

const onInit = () => { /* 앱 시작 */ }
MapsJsBridge.on('maps-bridge-sdk:init', onInit)

// 구독 해제:
MapsJsBridge.off('maps-bridge-sdk:init', onInit)

네이티브 UI 설정​

SDK를 로드하기 전후에 window.MAPS_WEBVIEW_META 객체를 통해 상태바 배경색 등의 네이티브 UI 설정을 선언할 수 있습니다. SDK는 초기화 시 이 객체를 읽어 자동으로 적용하므로, 페이지 로드 시 상태바 색상이 깜빡이는 현상을 방지할 수 있습니다.

<script>
  window.MAPS_WEBVIEW_META = {
    statusBar: {
      backgroundColor: '#ffffff',
    },
  }
</script>

전체 설정 레퍼런스는 WebView Meta를 참고하세요.

API 호출​

SDK가 초기화된 후에는 MapsJsBridge의 메서드를 직접 호출하세요. maps-bridge-sdk:init 이벤트 발생 이후 별도의 설정 없이 모든 메서드를 사용할 수 있습니다.

// 현재 웹뷰 닫기
MapsJsBridge.dismissSelf()

// 네이티브 클립보드에 텍스트 복사
MapsJsBridge.copyToClipboard({
  text: '복사할 텍스트',
  message: '복사되었습니다.',
})

// 기기의 기본 외부 브라우저에서 URL 열기
MapsJsBridge.externalLink({
  externalLink: 'https://example.com',
})

사용 가능한 전체 메서드 목록은 API 레퍼런스를 참고하세요.

SDK 환경 감지​

MapsJsBridge.isSupported를 사용하면 현재 환경이 Bridge SDK를 지원하는지(즉, 지원 버전 이상의 네이버 지도 앱 내에서 실행 중인지) 확인할 수 있습니다. 앱 외부에서 페이지가 렌더링될 수 있는 환경에서 폴백을 적용할 때 유용합니다.

if (MapsJsBridge.isSupported) {
  MapsJsBridge.dismissSelf()
} else {
  window.history.back()
}

SSR 환경에서는 getWebviewContext() 유틸리티를 사용하세요. 자세한 내용은 유틸리티 / getWebviewContext를 참고하세요.
