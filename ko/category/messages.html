메시지

📄️ dismissSelf()

현재 웹뷰를 닫고 사용자를 웹뷰를 열었던 네이티브 앱 화면으로 돌아가게 합니다.

📄️ sendClickCode()

네이티브 분석 레이어에 사용자 인터랙션 이벤트를 전송합니다. 버튼 클릭, 뷰 노출 등 의미 있는 페이지 내 이벤트를 네이티브 앱 텔레메트리와 함께 추적하는 데 활용하세요.

📄️ copyToClipboard()

네이티브 클립보드 API를 사용하여 문자열을 기기 클립보드에 복사하고, 선택적으로 복사 완료를 확인하는 네이티브 토스트 알림을 표시합니다.

📄️ saveBookmark()

현재 사용자의 네이버 지도 즐겨찾기에 장소 또는 위치 엔티티를 저장합니다.

📄️ share()

장소 또는 위치 엔티티를 공유하는 네이티브 공유 시트를 엽니다. 네이티브 앱은 제공된 id와 type을 기반으로 공유 페이로드(딥링크 URL, 미리보기 카드 등)를 구성합니다.

📄️ shareUrl()

임의의 URL을 공유하는 네이티브 공유 시트를 엽니다. 특정 네이버 지도 엔티티와 연결되지 않은 링크(예: 커스텀 딥링크 또는 웹 URL)를 공유할 때 사용하세요.

📄️ setStatusBar()

화면 상단에 시간, 배터리 등을 표시하는 네이티브 상태바의 배경색을 변경합니다. 페이지의 시각적 디자인에 맞춰 상태바를 일치시키는 데 사용하세요.

📄️ tel()

기기의 네이티브 전화 앱을 통해 지정한 번호로 전화를 겁니다.

📄️ externalLink()

네이버 지도 앱 웹뷰 외부의 기기 기본 브라우저에서 URL을 엽니다.

📄️ composite()

여러 Bridge API 호출을 하나의 메시지로 묶어 네이티브 앱에 전송합니다. 동시에 또는 원자적으로 적용되어야 하는 작업들을 일괄 처리하여 왕복 오버헤드를 줄일 때 사용하세요.

📄️ setWebViewMeta()

현재 웹뷰의 네이티브 UI 설정을 런타임에 업데이트합니다. WebView Meta에서 설명하는 선언적 window.MAPSWEBVIEWMETA 방식의 명령적 대응입니다.
