릴리스

NAVER Maps WebView Bridge SDK 릴리스 노트입니다. 설치 방법은 시작하기 — 설정을 참고하세요.

1.0.37​

릴리스일: 2026-05-08

새로운 기능​

  • openUrl() — HTTPS URL을 시스템 브라우저로 여는 API가 추가되었습니다. 자세한 내용은 openUrl() 문서를 참고하세요.

  • utils 서브 엔트리 — getWebviewContext 등 유틸리티 함수를 별도 서브 엔트리에서도 import할 수 있습니다. SDK bootstrap을 실행하지 않으므로 동적 import()에 안전합니다.

    const { getWebviewContext } = await import('@maps-service/maps-bridge/utils')

변경 사항​

  • init 요청 타임아웃 — SDK 초기화 시 보내는 init 요청에 기본 5초 타임아웃이 적용됩니다. 네트워크 또는 서버 응답이 지연되더라도 무기한 대기하지 않고 빠르게 실패 경로로 진입합니다.

1.0.36​

릴리스일: 2026-04-23

변경 사항​

  • serviceId 빈 값 체크 — SDK 스크립트 URL의 serviceId 쿼리 파라미터가 비어 있는 경우, 빈 값으로 초기화를 시도하지 않고 경고 로그를 남긴 뒤 자동 초기화를 건너뜁니다.

1.0.34​

릴리스일: 2026-04-03

변경 사항​

  • 내부 에러 모니터링 — SDK 내부에 격리된 Sentry 기반 에러 모니터링이 추가되었습니다. 호스트 페이지의 Sentry와 독립적으로 동작하며(전역 핸들러 미등록) SDK 코드에서 발생한 에러만 수집합니다.

1.0.33​

릴리스일: 2026-04-03

새로운 기능​

  • FOLLOW_CHANGED 네이티브 이벤트 — 네이티브에서 웹뷰로 follow_changed 이벤트가 새롭게 전달됩니다. MapsJsBridge.on('follow_changed', ...)으로 팔로우 상태 변경을 수신할 수 있습니다.

변경 사항​

  • setWebViewMeta — WebViewMeta에서 serviceId 필드가 제거되었습니다. 서비스 ID는 이제 SDK 스크립트 URL의 serviceId 쿼리 파라미터를 통해서만 전달됩니다.
  • 내부 에러 로깅 개선.
