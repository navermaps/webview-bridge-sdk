NAVER Maps WebView Bridge SDK

NAVER Maps WebView Bridge SDK는 네이버 지도 앱에 임베드된 웹뷰가 네이티브 레이어와 양방향으로 통신할 수 있도록 지원하는 JavaScript SDK입니다. iOS/Android 플랫폼별 네이티브 API를 통합된 JavaScript 인터페이스로 추상화하여, 플랫폼별 코드를 직접 작성하지 않고도 네이티브 기능을 호출하고 네이티브 이벤트를 수신할 수 있습니다.

이 문서는 네이버 지도 앱 내에서 웹뷰 기반 서비스를 개발하는 파트너 개발자를 위해 작성되었습니다.

동작 원리​

SDK는 window에 전역 MapsJsBridge 객체를 제공합니다. 웹 앱에서 이 객체의 메서드를 호출하면, SDK가 JSON 메시지로 직렬화하여 postMessage를 통해 네이티브 레이어로 전달합니다. 네이티브의 응답은 커스텀 DOM 이벤트로 디스패치되며, SDK가 이를 원래의 Promise로 resolve합니다.

주요 기능​

  • Promise 기반 API — 모든 메서드가 Promise를 반환하므로 async/await와 함께 간편하게 사용할 수 있습니다.
  • 크로스플랫폼 추상화 — iOS와 Android의 네이티브 브릿지 차이를 SDK가 투명하게 처리합니다. 하나의 코드베이스로 두 플랫폼 모두 동작합니다.
  • 환경 감지 — MapsJsBridge.isSupported를 통해 런타임에 페이지가 네이버 지도 앱 내에서 실행 중인지 확인할 수 있습니다. 앱 외부에서 접근 시 네이티브 기능을 조건부로 비활성화하거나 폴백을 적용하는 데 활용하세요.
  • 네이티브 UI 제어 — 네이티브 앱 UI(상태바 색상, 하단 내비게이션 표시 여부)를 JavaScript에서 직접 구성할 수 있습니다. 페이지 로드 시 WebViewMeta를 통한 선언적 방식과 런타임에 API를 호출하는 명령적 방식 모두 지원합니다.
