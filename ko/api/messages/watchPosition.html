watchPosition() / clearWatchPosition()

위치 변경을 지속적으로 구독합니다. 갱신된 위치는 콜백으로 전달되며, 실제 위치 조회와 권한 처리는 네이티브 앱에 위임합니다.

getCurrentPosition()과 마찬가지로 요청을 보내기 전에 내부적으로 requestPermission('geolocation')을 먼저 호출합니다.

최소 앱 버전​

6.11.0

시그니처​

MapsJsBridge.watchPosition(
  successCallback: GeolocationSuccessCallback,
  errorCallback?: GeolocationErrorCallback,
): void

파라미터​

successCallback(position: GeolocationPosition) => voidRequired
위치가 갱신될 때마다 호출되는 콜백입니다.
errorCallback(error: GeolocationPositionError) => voidOptional
위치 갱신 중 에러가 발생했을 때 호출되는 콜백입니다. 에러가 발생해도 watch 자체는 중단되지 않습니다.

반환값​

아무 값도 반환하지 않습니다. 구독을 식별하는 id 자체가 없으며, 해제는 항상 clearWatchPosition()으로 합니다.

여러 곳에서 동시에 호출 가능

watchPosition()은 여러 곳에서 동시에 호출할 수 있습니다. 각 호출의 successCallback/errorCallback이 모두 등록되고, 위치가 갱신될 때마다 등록된 모든 콜백이 함께 호출됩니다. 네이티브 앱에는 여전히 위치 watch 요청을 한 번만 보냅니다 — 이미 watch 중일 때 추가로 호출하면 네이티브 재요청이나 권한 재확인 없이 로컬 콜백만 추가됩니다.

timeout은 최초 1회 응답에만 적용

getCurrentPosition()과 동일하게 고정 제한시간(10초, DEFAULT_GEOLOCATION_TIMEOUT)이 있지만, 최초 1회 응답에만 적용됩니다. 첫 응답이 없으면 그 시점에 등록되어 있는 모든 watchPosition() 호출자의 errorCallback에 { code: 3, message: 'Timeout expired' }를 알리지만, watch 자체는 중단되지 않습니다. 이후 갱신에는 이 timeout이 적용되지 않습니다.

clearWatchPosition()​

MapsJsBridge.clearWatchPosition(): void

파라미터가 없습니다. 호출하면 SDK는 (1) 현재 등록되어 있는 모든 watchPosition() 콜백을 한번에 해제하고 (2) 네이티브 앱에 메시지를 보내 위치 갱신 자체를 중단시킵니다.

등록된 모든 구독이 한번에 해제됩니다

서로 다른 곳에서 각각 watchPosition()을 호출한 상태라도, clearWatchPosition()을 한 번 호출하면 그 시점에 등록된 모든 구독이 함께 해제됩니다. 특정 호출만 골라 해제할 수 없습니다 — 개별 해제가 필요하면 앱에서 별도로 상태를 관리해야 합니다.

웹뷰 파괴/이동 시 자동 정리

clearWatchPosition()을 명시적으로 호출하지 않아도, 웹뷰가 파괴되거나 다른 URL로 이동(reload 포함)하면 네이티브 앱이 웹뷰의 생명주기 이벤트에 연동해 활성 watch를 자동으로 정리합니다.

GeolocationPosition (성공) / GeolocationPositionError (에러)​

필드 상세는 getCurrentPosition() 문서를 참고하세요 — getCurrentPosition()과 동일한 타입이며 추가 필드는 없습니다.

예시​

MapsJsBridge.watchPosition(
  (position) => {
    console.log('position updated', position.coords)
  },
  (error) => {
    console.error(error.code, error.message)
  },
)

// 위치 추적이 더 이상 필요 없을 때
// (같은 시점에 다른 곳에서 호출한 watchPosition() 콜백도 함께 해제된다)
MapsJsBridge.clearWatchPosition()
