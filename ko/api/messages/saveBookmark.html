saveBookmark()

현재 사용자의 네이버 지도 즐겨찾기에 장소 또는 위치 엔티티를 저장합니다.

앱이 즐겨찾기 위젯을 띄우고 처리 결과를 웹뷰로 다시 전달하므로, 이 API 는 사용자가 위젯을 닫는 시점에 처리되는 Promise 를 반환합니다.

시그니처​

MapsJsBridge.saveBookmark(params: SaveBookmarkParams): Promise<MapsBridgeMessage>

파라미터​

idstringRequired
즐겨찾기에 추가할 엔티티의 고유 식별자.
typestringRequired
엔티티 유형. 허용 값: place | subway_station | bus_station | address | simple_poi

반환 값​

정보

응답값은 SDK 1.0.42 버전 이상부터 사용할 수 있습니다. 이전 버전에서는 saveBookmark() 가 아무 값도 반환하지 않습니다.

앱이 bookmark_changed 응답을 웹뷰로 전달하면 Promise 가 처리됩니다.

  • 앱이 요청을 정상적으로 처리한 경우, 수신한 응답 메시지 전체와 함께 resolve 됩니다.
  • 앱이 실패를 알린 경우(메시지에 error 필드가 포함된 경우), 수신한 응답 메시지 전체와 함께 reject 됩니다.
typestringRequired
saveBookmark() 응답은 항상 bookmark_changed 입니다.
idstringRequired
앱에서 생성한 응답 메시지의 식별자.
data.idstringRequired
요청한 엔티티 식별자.
data.typestringRequired
요청한 엔티티 유형.
data.changedbooleanRequired
즐겨찾기 상태가 실제로 변경되었는지 여부. 사용자가 아무 변경 없이 위젯을 닫으면 false 입니다.
data.isBookmarkedbooleanOptional
변경 후의 즐겨찾기 상태. 저장되었으면 true, 삭제되었으면 false. changed 가 false 인 경우에는 포함되지 않습니다.
error.messagestringOptional
실패 사유 (예: invalid poi, not logged in). 이 필드가 포함되면 Promise 는 reject 됩니다.
meta.callbackIdstringRequired
이 응답에 대응하는 요청 메시지의 id. SDK 가 요청과 응답을 연결하는 데 내부적으로 사용하므로 직접 읽을 필요는 없습니다.
응답 타임아웃 없음

이 Promise 에는 타임아웃이 없습니다. 사용자가 즐겨찾기 위젯을 열어둔 채로 두면 앱이 응답할 때까지 계속 pending 상태로 남아 있습니다. 이 Promise 에 UI 를 무기한 묶어두지 마세요. 사용자가 변경 없이 위젯을 닫은 경우에도 앱은 changed: false 로 응답합니다.

예시​

try {
  const message = await MapsJsBridge.saveBookmark({
    id: '523890342',
    type: 'place',
  })

  const { changed, isBookmarked } = message.data ?? {}

  if (changed) {
    console.log(isBookmarked ? '즐겨찾기에 추가되었습니다.' : '즐겨찾기에서 삭제되었습니다.')
  } else {
    // 사용자가 변경 없이 위젯을 닫은 경우
  }
} catch (message) {
  console.error(message.error?.message)
}

응답 예시​

위에서 설명한 meta.callbackId 필드는 아래 예시에서 생략했습니다.

1. 즐겨찾기 상태가 변경된 경우​

{
  "id": "9f0a3e4c-1c7d-4f2a-9a3b-0f1d2c3b4a5e",
  "type": "bookmark_changed",
  "data": {
    "id": "523890342",
    "type": "place",
    "changed": true,
    "isBookmarked": true
  }
}

2. 변경 없이 위젯을 닫은 경우​

{
  "id": "9f0a3e4c-1c7d-4f2a-9a3b-0f1d2c3b4a5e",
  "type": "bookmark_changed",
  "data": {
    "id": "523890342",
    "type": "place",
    "changed": false
  }
}

3. 앱에서 에러가 발생한 경우​

{
  "id": "9f0a3e4c-1c7d-4f2a-9a3b-0f1d2c3b4a5e",
  "type": "bookmark_changed",
  "data": {
    "id": "523890342",
    "type": "place",
    "changed": false
  },
  "error": {
    "message": "invalid poi"
  }
}
