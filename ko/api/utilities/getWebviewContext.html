getWebviewContext()

User-Agent 문자열을 파싱하여 페이지가 지원되는 버전의 네이버 지도 앱 내에서 실행 중인지 확인하고, 앱의 현재 UI 컨텍스트(테마 및 화면 방향)를 추출합니다.

이 함수는 서버와 클라이언트 환경 모두에서 동작하므로, 페이지가 브라우저에 도달하기 전에 앱 컨텍스트를 감지해야 하는 SSR 프레임워크(예: 서버 사이드에서 올바른 테마를 렌더링하기 위해)에 적합합니다.

시그니처​

function getWebviewContext(params: {
  userAgentHeader: string
  supportedAppVersion?: string
}): GetWebviewContextResult

파라미터​

userAgentHeaderstringRequired
파싱할 User-Agent 문자열. 클라이언트에서는 window.navigator.userAgent를, 서버에서는 User-Agent 요청 헤더를 전달하세요.
supportedAppVersionstringOptional
SDK 지원에 필요한 최소 앱 버전. 기본값은 6.0.0입니다. 이 버전 미만이면 isSupported: false가 반환됩니다.
default: 6.0.0

반환값​

isSupportedbooleanRequired
지원되는 버전 이상의 네이버 지도 앱 내에서 페이지가 실행 중이면 true. 그렇지 않으면 false (예: 일반 브라우저, 구버전 앱).
themestringOptional
앱의 현재 색상 테마: light 또는 dark. isSupported가 true일 때만 제공됩니다.
orientationstringOptional
기기의 현재 화면 방향: portrait 또는 landscape. isSupported가 true일 때만 제공됩니다.

User-Agent 형식​

네이버 지도 앱이 웹뷰를 열 때 User-Agent 문자열에 다음 토큰을 추가합니다.

WebViewSDK(map; {theme}; {orientation})

예시​

클라이언트 사이드:

import { getWebviewContext } from '@maps-service/maps-bridge'

const { isSupported, theme, orientation } = getWebviewContext({
  userAgentHeader: window.navigator.userAgent,
})

if (isSupported) {
  console.log(`테마: ${theme}, 화면 방향: ${orientation}`)
}

서버 사이드 (Next.js 예시):

import { getWebviewContext } from '@maps-service/maps-bridge'

export async function getServerSideProps(context) {
  const userAgent = context.req.headers['user-agent'] ?? ''
  const { isSupported, theme } = getWebviewContext({ userAgentHeader: userAgent })

  return {
    props: {
      initialTheme: theme ?? 'light',
      isSupportedApp: isSupported,
    },
  }
}
팁

클라이언트에서 테마 및 화면 방향 변경에 반응할 때는 CSS 미디어 쿼리를 사용하세요. getWebviewContext()는 SSR 시 초기값이 필요하거나 서버 사이드 로깅이 필요한 경우에만 사용하세요.
