Messages

📄️dismissSelf()

Closes the current webview and returns the user to the native app screen that opened it.

📄️sendClickCode()

Reports a user interaction event to the native analytics layer. Use this to log button clicks, view impressions, or other meaningful in-page events so they can be tracked alongside native app telemetry.

📄️copyToClipboard()

Copies a string to the device clipboard using the native clipboard API, then optionally shows a native toast notification to confirm the action.

📄️saveBookmark()

Saves a place or location entity to the current user's NAVER Maps bookmarks.

📄️share()

Opens the native share sheet to share a place or location entity. The native app constructs the share payload (deep-link URL, preview card, etc.) from the supplied id and type.

📄️shareUrl()

Opens the native share sheet to share an arbitrary URL. Use this when you want to share a link that is not tied to a specific NAVER Maps entity (e.g. a custom deep-link or a web URL).

📄️setStatusBar()

Changes the background color of the native status bar (the OS bar at the top of the screen showing time, battery, etc.). Use this to match the status bar to your page's visual design.

📄️tel()

Initiates a phone call to the given number via the device's native dialer.

📄️externalLink()

Opens a URL in the device's default external browser, outside of the NAVER Maps app webview.

📄️composite()

Sends multiple Bridge API calls to the native app in a single message. Use this to batch operations that should be applied atomically or at the same time, reducing round-trip overhead.

📄️setWebViewMeta()

Updates native UI configuration for the current webview at runtime. This is the imperative counterpart to the declarative window.MAPSWEBVIEWMETA approach described in WebView Meta.

📄️openUrl()

Opens a URL in an in-app webview, system webview, or auth browser depending on the browser value.

📄️requestPermission()

Requests an OS-level permission (e.g. location) before you actually use a feature that needs it.

📄️getCurrentPosition()

Retrieves the current location once through a callback interface, while delegating the actual location lookup and permission handling to the native app.

📄️watchPosition() / clearWatchPosition()

Subscribes to ongoing location updates through a callback interface, while delegating the actual location lookup and permission handling to the native app.

📄️openPartnerAuthUrl()

Opens a partner authentication URL in the authentication browser appropriate for the current platform.
