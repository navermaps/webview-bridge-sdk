composite()

Sends multiple Bridge API calls to the native app in a single message. Use this to batch operations that should be applied atomically or at the same time, reducing round-trip overhead.

Signature​

MapsJsBridge.composite(params: CompositeParams): void

Parameters​

dataarrayRequired
An ordered list of message objects to send. Each item corresponds to a single Bridge API call.

Each item in data:

typestringRequired
The message type of the Bridge API to invoke (e.g. set_status_bar, share).
dataobjectOptional
The parameters for that API call. Shape matches the corresponding API's parameter object.

Example​

The following example updates the status bar color and triggers a share sheet in a single native call:

MapsJsBridge.composite({
  data: [
    {
      type: 'set_status_bar',
      data: {
        color: '#ff3300',
      },
    },
    {
      type: 'share',
      data: {
        id: '11576170',
        type: 'place',
        message: 'Gyeongbokgung Palace',
      },
    },
  ],
})
